## 前言

GFW 的存在，国内大部分地区访问国际互联网时会遇到 DNS 污染、IP 阻断、SNI/协议特征识别、连接重置、路由拥塞等问题。教育网也无法完全幸免，只是不同学校、不同出口、不同时间段的表现会有差异。

严格来说，HTTPS 本身并不是“第一步做 DNS”，而是浏览器或系统在发起连接前通常需要先把域名解析成 IP。如果 DNS 被污染，浏览器还没来得及建立 TLS 连接，就已经拿到了错误的 IP；如果 DNS 正常，也可能在后续 TCP、TLS、QUIC 或 HTTP 层面被干扰。

本文介绍两种常见思路：

1. **单机直连**：买一台对国内线路较好的海外 VPS，直接作为代理服务器使用。
2. **线路机 + 落地机链式代理**：用一台“线路机”负责把国内流量稳定送出国，再用一台“落地机”负责最终访问目标网站。

本文仅供网络学习、科研测试和合规用途。请遵守所在地法律法规、服务条款和学校/公司的网络使用规范，不要用于攻击、盗号、刷量、诈骗、侵犯版权等非法行为。

## 概念解释

### 线路

很多新手一开始会把“服务器地区”和“线路质量”混为一谈。比如看到“香港 VPS”就以为一定快，看到“美国 VPS”就以为一定慢。实际体验并不只由地理距离决定，还取决于运营商之间的路由、拥塞情况、回程质量、晚高峰负载和 IP 质量。

可以把访问一个海外网站理解成寄快递：

```text
你的电脑
  ↓
本地运营商
  ↓
国内骨干网
  ↓
国际出口
  ↓
海外运营商 / 数据中心
  ↓
目标网站
```

这里每一段都可能影响体验。

#### 什么是路由

“路由”就是数据包从你这里到服务器那里实际走过的路径。它不一定是地图上的最短路径，而是由运营商之间的互联协议、商业结算、链路容量和网络策略共同决定的。

比如你在上海访问东京服务器，理论上距离很近，但如果路由绕到美国再回来，延迟就会非常难看；相反，如果从国内骨干网直接到日本优质出口，体验就会非常好。

判断路由常用工具有：

```bash
ping 目标IP
traceroute 目标IP
mtr 目标IP
nexttrace 目标IP
```

其中 `ping` 主要看延迟和丢包，`traceroute` / `mtr` / `nexttrace` 可以看中间经过了哪些运营商节点。

#### 国内三大运营商

国内普通家庭宽带主要是：

- 中国电信
- 中国联通
- 中国移动

三家运营商的国际出口策略不同，所以同一台海外 VPS，电信用户可能很快，移动用户可能很慢，反过来也可能成立。因此买 VPS 时经常会看到商家写：

- 电信优化
- 联通优化
- 移动优化
- 三网优化
- 三网回程优化
- 三网 CN2 / CMI / AS9929

这些词的核心意思是：这台服务器到国内三大运营商的路由质量相对更好。

#### 电信骨干网、CN2、GIA

中国电信常见说法有：

| 名称             | 常见理解              | 特点                                                 |
| ---------------- | --------------------- | ---------------------------------------------------- |
| 163 / AS4134     | 普通电信骨干网        | 便宜、覆盖广，但晚高峰容易拥塞                       |
| CN2 GT           | 半优化 CN2            | 通常部分路由走 CN2，质量比普通 163 好，但不如 GIA 稳 |
| CN2 GIA          | 高质量 CN2 国际精品网 | 价格高，回程质量好，晚高峰更稳                       |
| CTGNet / AS23764 | 电信国际网络相关资源  | 不同商家宣传方式不同，需实测确认                     |

CN2 GIA 是代理圈里非常常见的优质线路关键词。它的优势不是“延迟永远最低”，而是“拥塞更少、回程更稳、晚高峰不容易炸”。如果你是电信用户，CN2 GIA 通常是非常优先的选择。

判断是否可能是 CN2，常见方法是看回程路由里是否出现 `59.43.*.*` 或相关 AS 信息。但这只能作为参考，不能只看一个 traceroute 就下结论，因为去程、回程可能不一样，不同时间段也可能变化。

#### 联通 AS4837、AS9929

中国联通常见说法有：

| 名称          | 常见理解             | 特点                       |
| ------------- | -------------------- | -------------------------- |
| AS4837 / 169  | 普通联通骨干网       | 覆盖广，价格相对低         |
| AS9929 / CUII | 联通高质量国际线路   | 稳定性和晚高峰表现通常更好 |
| AS10099       | 中国联通国际相关网络 | 海外互联中经常出现         |

如果你是联通宽带用户，看到商家写“联通 AS9929 回程”通常是加分项。尤其是美国洛杉矶、日本、香港、新加坡等地区，AS9929 往往比普通线路更稳定。

#### 移动 CMI、CMIN2

中国移动常见说法有：

| 名称             | 常见理解                       | 特点                             |
| ---------------- | ------------------------------ | -------------------------------- |
| CMI / AS58453    | 中国移动国际网络               | 移动用户访问海外时经常遇到       |
| CMIN2 / AS58807  | 移动较新的高质量国际线路宣传名 | 商家宣传中常见，需实测确认       |
| 普通移动国际出口 | 普通路由                       | 有时表现很好，有时晚高峰波动明显 |

移动用户比较特殊。移动到某些香港、日本、新加坡节点可能表现非常好，但到一些普通美国 VPS 可能绕路或晚高峰波动。移动用户选线路时，不要只看“CN2”，还要看商家是否明确写了“移动优化”“CMI”“CMIN2”或有移动回程测试图。

#### 什么叫三网优化

“三网优化”就是电信、联通、移动三家都尽量走比较好的回程线路。理想状态是：

```text
电信用户 → CN2 GIA / CTGNet
联通用户 → AS9929 / 优质联通回程
移动用户 → CMI / CMIN2 / 优质移动回程
```

### 线路机

“线路机”就是专门负责把你从国内送到海外的那台机器。

它的核心价值是：**线路好**。

线路机不一定要 IP 很干净（而且也大概率不干净，整个IP段都是线路机，怎么可能好），它最重要的是国内到它的连接质量好，尤其是晚高峰稳定。

如果只用一台 VPS 直连，那么这台机器既是线路机，也是落地机。但如果做链式代理，线路机只负责第一跳，不负责最终访问网站。

### 落地机

“落地机”就是最终访问目标网站的那台机器。

它的核心价值是：**IP 质量好**。

比如访问 ChatGPT、GitHub、Google、Telegram、部分流媒体或开发者平台时，对方看到的不是你的真实 IP，而是落地机的 IP。因此落地机的 IP 质量非常重要。

### 家宽

“家宽”指的是家庭宽带 IP，也就是普通居民家里的 ISP 分配的 IP。它和数据中心 VPS 最大的区别是：

| 类型              | 来源              | IP 形象     | 优点               | 缺点                         |
| ----------------- | ----------------- | ----------- | ------------------ | ---------------------------- |
| VPS / 数据中心 IP | 云厂商、机房、IDC | 服务器 IP   | 便宜、稳定、易管理 | 容易被识别为代理/VPN/机房    |
| 家宽 IP           | 真实家庭宽带      | 普通用户 IP | IP 质量高，风控低  | 贵、少、维护麻烦、合规风险高 |

很多网站会对数据中心 IP 更敏感，因为大量爬虫、批量注册、代理池、垃圾邮件都来自机房 IP。家宽 IP 更像普通用户，所以风控往往低一些。

但家宽价格通常很高，而且来源复杂，可能涉及转租、共享、灰色代理、隐私风险和稳定性问题。本文不展开讨论家宽，也不建议新手一上来就碰家宽。对普通学习和日常访问来说，优先考虑“优质线路机 + 干净落地机”就够了。

### IX

IX 是 Internet Exchange 的缩写，常见完整说法是 IXP，即 Internet Exchange Point，互联网交换中心。

它可以理解成一个大型“网络中转大厅”。很多运营商、云厂商、CDN、数据中心、内容平台会把自己的网络接入到同一个交换中心，然后彼此直接交换流量。

不用 IX 时，A 网络访问 B 网络可能要经过第三方运营商：

```text
A 网络 → 上游运营商 → 另一个上游运营商 → B 网络
```

有 IX 时，如果 A 和 B 都在同一个 IX，并且建立了 Peering，就可能变成：

```text
A 网络 → IX 交换机 → B 网络
```

### IX 前置

“IX 前置”可以理解为：在目标落地机前面，放一台靠近大型 IX 或与目标网络互联较好的机器，让它负责接入和转发流量。

```text
你 → IX 前置线路机 → 落地机 → 目标网站
```

IX 必须有大厂服务器，也就是说需要自备国内大厂服务器+海外落地机。

### 链式代理

链式代理就是把多个代理节点串起来，让流量按顺序经过它们。

最简单的单机代理是：

```text
你 → VPS → 目标网站
```

链式代理是：

```text
你 → 线路机 → 落地机 → 目标网站
```

也可以更复杂：

```text
你 → 国内入口 → 香港线路机 → 日本前置 → 美国落地 → 目标网站
```

不建议链太长。每多一跳，就多一点延迟。链式代理的核心价值是把不同机器的优点组合起来：

- 线路机：国内连接质量好

- 落地机：IP 质量好

比如你有一台香港 CN2 GIA VPS，国内访问非常稳，但 IP 被很多网站识别成数据中心代理；你又有一台瑞士普通 VPS，IP 很干净，但国内直连很慢。那可以这样：

```text
国内设备 → 香港 CN2 GIA 线路机 → 瑞士落地机 → ChatGPT / GitHub
```

这样国内到香港这一段很稳，最终访问网站时又显示瑞士落地机 IP。

链式代理要注意：

1. 线路机和落地机之间必须快，否则整体还是慢。
2. 落地机 IP 要干净，否则链式没有意义。
3. 链路越长越容易出问题。
4. 不要把所有协议都无脑套链，可以合理分流

## 线路机选择

线路机的首要任务不是“IP 好看”，而是“国内到它好用”。选择时建议按下面几个维度判断。

### 地区选择

常见地区大致可以这样理解：

| 地区   | 优点     | 缺点     |
| ------ | -------- | -------- |
| 香港   | 延迟低   | 贵       |
| 日本   | 延迟低   | 贵       |
| 新加坡 | 延迟低   | 贵       |
| 洛杉矶 | 价格中等 | 延迟中等 |
| 欧洲   | 价格中低 | 延迟略高 |

美西节点是最推荐的，欧洲价格低也可以考虑。
